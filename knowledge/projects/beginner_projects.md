# Beginner Cybersecurity Projects

## Python log analyzer
Goal: parse a synthetic authentication log and count successful and failed logins. Skills: Python files, dictionaries, timestamps, data validation, and reporting. Deliverables: source code, sample input, tests, and a README explaining limitations.

## Network fundamentals notebook
Goal: document DNS lookups, HTTP request anatomy, common ports, and a network diagram using a local lab. Skills: networking and clear technical writing. Do not scan systems without permission.

## Secure web application checklist
Goal: create a checklist for authentication, authorization, input validation, error handling, dependency updates, and secrets management. Apply it to a small app you own.

## Digital evidence integrity demo
Goal: compute SHA-256 hashes for sample files, copy them, and verify whether the hashes match. Explain that matching hashes support integrity checking but do not prove where a file came from.

## Cloud least-privilege design
Goal: diagram a fictional application and propose roles with only the permissions needed. Do not upload secrets or expose real cloud credentials.

## Portfolio quality
Each project should include a clear goal, safe test scope, setup instructions, sample data, reproducible steps, results, limitations, and references. A project is evidence of learning, not a guarantee of employment.
