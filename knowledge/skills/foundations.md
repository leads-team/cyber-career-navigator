# Cybersecurity Foundations

## Networking
Learn IP addresses, subnet basics, DNS, TCP/UDP, ports, HTTP/HTTPS, routing, and how to read basic network diagrams. Practice with local labs and synthetic traffic.

## Linux and operating systems
Practice navigation, files, permissions, processes, services, logs, and command-line text processing. Learn basic Windows event and account concepts as well.

## Programming
Python is useful for file processing, APIs, automation, and small analysis scripts. JavaScript and web fundamentals are especially useful for application security. Focus on readable, tested code rather than collecting languages.

## Security concepts
Understand confidentiality, integrity, availability, authentication, authorization, least privilege, patching, backups, logging, threat modeling, and incident response.

## Learning approach
Alternate study with small, documented projects. Keep a portfolio README explaining the problem, dataset, steps, result, limitations, and what you learned. Use only authorized labs and data.
