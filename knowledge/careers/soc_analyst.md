# SOC Analyst

## Role overview
A Security Operations Center (SOC) analyst monitors security telemetry and alerts, investigates suspicious activity, documents findings, and escalates or supports incident response according to an organization's procedures. Duties vary by employer and seniority.

## Core skills
- Networking: IP addresses, DNS, HTTP/HTTPS, ports, TCP/UDP, and basic packet concepts.
- Operating systems: Linux command line and Windows event concepts.
- Log analysis: timestamps, usernames, source addresses, event IDs, and patterns across events.
- SIEM concepts: searching, filtering, correlating, and investigating events in a Security Information and Event Management platform.
- Incident handling: triage, evidence preservation, clear notes, escalation, and communication.
- Scripting: basic Python or shell skills can help automate repetitive analysis.

## Beginner learning roadmap
1. Learn networking fundamentals and common protocols.
2. Practice Linux commands and understand Windows security events.
3. Read sample authentication, web-server, and firewall logs.
4. Learn how SIEM queries filter and correlate events using a legal training dataset.
5. Write incident notes that state the evidence, uncertainty, impact, and recommended next step.

## Beginner projects
- Parse a sample authentication log and count failed logins by source address.
- Create a small dashboard of event counts using a synthetic dataset.
- Write a triage report for a simulated phishing alert, clearly separating observations from hypotheses.
